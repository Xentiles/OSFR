# Security policy

## Supported versions

OSFR is an active research prototype. Security fixes are applied to the latest `main` branch; no released version line is currently supported separately.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when available. If it is not available, contact the repository owner through the [Xentiles GitHub profile](https://github.com/Xentiles) with a request for a private reporting channel.

Include:

- the affected files and revision;
- reproduction steps or a proof of concept;
- the expected impact;
- any proposed mitigation;
- whether the issue has been disclosed elsewhere.

You should receive an acknowledgement within seven days. Because this is a research project rather than a deployed service, response and release timelines depend on severity and reproducibility.
